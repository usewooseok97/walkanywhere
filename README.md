# Walk Anywhere — AI 생성 가상 공간 1인칭 산책 서비스 랜딩 페이지

"문장 하나면, 당신이 걷고 싶은 세계가 열립니다."
공감 → 갈등 → 해결의 스토리 구조를 그대로 따라가는 한 페이지짜리 랜딩이고,
3장 '해결'에는 문장을 입력하면 즉석에서 3D 공간이 만들어지고 코스를 따라 걸어 볼 수 있는 미니 데모가 들어 있습니다.

## 열어 보기

- 가장 쉬운 방법: `index.html`을 더블클릭해 브라우저(Chrome, Edge, Safari 최신 버전)에서 엽니다.
  글꼴(Pretendard, Noto Serif KR)과 three.js를 CDN에서 받아오므로 인터넷 연결이 필요합니다.
- 로컬 서버로 띄우려면 이 폴더에서 아래 중 하나를 실행합니다.

```bash
npx serve .             # npx: npm 패키지를 설치 없이 바로 실행 / serve: 현재 폴더(.)를 정적 서버로 띄움
python3 -m http.server  # -m http.server: 파이썬 내장 모듈로 현재 폴더를 8000번 포트에 서빙
```

- 주소 뒤에 `?walk=문장`을 붙이면 페이지가 열리자마자 그 문장으로 데모를 시작합니다.
  예) `index.html?walk=노을 지는 제주 해변`

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 마크업 + 산책 데모 스크립트(`<script type="module">`) |
| `styles.css` | 스타일. 1·2장은 밤(잉크 블루), 3장부터는 새벽(연보라 흰색)으로 색이 바뀝니다 |
| `README.md` | 이 문서 |

데모 스크립트를 HTML 안에 둔 이유: 별도 `.js` 모듈 파일은 `file://`로 열면 Chrome이 차단합니다. 더블클릭만으로 동작하게 하려고 인라인으로 넣었습니다. 서버로만 서빙할 거라면 `walk.js`로 분리해도 됩니다.

## 데모 조작 방식

| 조작 | 방법 |
| --- | --- |
| 시선 | 화면을 마우스/손가락으로 끌어서 둘러보기 (360도) |
| 걷기 / 정지 | 하단 바의 토글 버튼, 또는 `Space` |
| 속도 1~5 | 하단 바의 숫자 버튼, 또는 키보드 `1`~`5`, `↑`/`↓` |
| 코스 | 문장마다 정해진 산책 코스 한 바퀴. 바닥에 길이 그려지고, 하단에 진행률이 표시됩니다 |
| 전체 화면 | 우측 상단 버튼 |

속도 값은 `index.html`의 `SPEEDS` 배열(m/s)에서 바꿀 수 있습니다.

## 문장 → 세계 규칙

`THEME_RULES`의 정규식이 문장에서 장소를 고릅니다(위에서부터 먼저 맞는 것).

| 테마 | 키워드 예 | 코스 |
| --- | --- | --- |
| 화성 | 화성, 우주, 행성 | 들길(원점에서 출발하는 랜덤 루프) |
| 설원 | 눈, 겨울, 자작나무 | 들길 |
| 해변 | 해변, 바다, 제주, 파도 | 물가를 따라 갔다가 모래 위쪽으로 돌아오는 타원 |
| 도시 | 네온, 도시, 서울, 야경 | 길 한쪽으로 내려갔다가 반대쪽으로 돌아오는 거리 |
| 옛 동네 | 옛 동네, 골목, 시골, 1990년대 | 거리 |
| 사막 | 사막, 사구, 선인장 | 들길 |
| 숲 | 숲, 나무, 산, 오솔길 | 들길 |
| (기본) 초원 | 그 외 | 들길 |

여기에 시간·날씨 수식어가 겹쳐집니다: 밤 / 노을 / 새벽 / 비 / 안개.
같은 문장은 항상 같은 세계와 같은 코스로 열립니다(문장을 시드로 씁니다).

## 바꾸기 쉬운 것들

- 서비스 이름: `index.html`에서 `Walk Anywhere`를 검색해 바꿉니다(내비, 푸터, `<title>`).
- 색: `styles.css` 맨 위의 CSS 변수(`--ink`, `--dawn`, `--lamp` 등).
- 예시 문장(칩): 3장의 `<ul class="chips">` 목록.
- 코스 모양: `makeCourse()` — 테마별 제어점을 바꾸면 코스가 바뀝니다.
- 소품: `PROPS` 객체에 테마별 생성 함수가 있습니다.

## 이 데모의 범위

페이지의 3D 장면은 브라우저 안에서 규칙으로 즉석 생성한 "체험용 미니 데모"입니다.
실제 서비스에서는 AI(예: World Labs Marble)가 생성한 3D 공간 위에 코스를 깔고 같은 조작 방식으로 걷게 됩니다.
페이지 안의 문구도 그렇게 적혀 있습니다.
