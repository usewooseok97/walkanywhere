# Walk Anywhere

"문장 하나면, 당신이 걷고 싶은 세계가 열립니다."
접속하면 바로 풀숲 길을 걷기 시작하고, 가고 싶은 곳을 고르거나 적으면 안개 너머로 그 세계가 이어집니다.
목적지에 도착하면 그 길을 저장할 수 있습니다.

- `/` — 산책 화면 (메인)
- `/about` — 소개 페이지 (공감 → 갈등 → 해결 스토리 + 미니 데모)
- `/admin` — 관리자 전용: 불편사항, 통계(어디를 걷고 싶어 하는지·어떤 걸음으로 걷는지·어떤 간판을 누르는지), 사용자(비밀번호 초기화), 관리자 비밀번호 변경. 처음 비밀번호 `admin1234`, 로그인 후 바꾸세요. `/stats`는 여기로 넘어갑니다.

## 흐름

1. 맑은 낮의 들판 길을 걷는다. 마우스를 움직여 둘러보고(화면 클릭으로 시작), `Esc`로 멈추고 마우스를 꺼낸다.
2. 하단 카드 "오늘은 어디로 가볼까?" — 랜덤 선택지 2개, 또는 챗 입력.
3. "거기로 가자." → 안개가 짙어졌다 걷히며 목적지 세계로 길이 이어진다.
4. 목적지까지 280~420 m. 길가의 간판이 달린 건물·표지판은 그 장소에 어울리는 웹사이트 링크다.
   한 번 클릭하면 "무슨 건물일까?" 정보 카드가 뜨고 걸음이 가장 느려진다. 다시 클릭하면 새 탭에서 열린다.
5. 끝에는 장소에 맞는 목적지 건물(해변=등대, 숲·설원=오두막, 사막=오아시스 돔, 도시=전망 타워, 옛 동네=시장 입구, 화성=기지 돔, 초원=풍차).
6. "목적지에 도착했다." → 저장할지 묻는다. 처음 저장할 때 아이디(2~10자, 중복 불가)·비밀번호(영문+숫자 8자 이상)·닉네임으로 가입하거나 로그인한다. 저장하지 않으면 처음 길로 돌아간다.
7. 로그인하면 "어디로 가볼까?" 카드에 내가 저장한 길이 함께 떠서 다시 갈 수 있다.

### 랜드마크

`js/landmarks.js`에 한국 20곳 + 세계 35곳이 들어 있다(에펠탑, 경복궁, 후지산, 타지마할, 콜로세움, 금문교, 마추픽추 …).
문장에 이름이 들어 있으면 그 장소의 환경·시각·추천 사이트를 쓰고, 길 끝에 `js/archetypes.js`의 원형(격자 철탑, 궁궐 문, 개선문, 현수교, 원형 경기장, 토리이 길, 사원, 모스크, 성, 동상, 전망탑, 마천루, 피라미드, 산봉우리, 협곡, 계단식 유적, 성벽, 환상열석, 하얀 마을, 비탈 마을, 게르, 유리 건물 등 30여 종)으로 지은 건물이 선다. 선택지에도 "노을 지는 에펠탑"처럼 랜드마크가 섞여 나온다.

### 소리

`audio/` 의 CC0·CC BY 녹음(파도, 새, 귀뚜라미, 비, 바람, 숲, 시냇물, 카페 웅성거림)을 끊김 없이 이어 틀고, 파일을 못 불러오면 Web Audio 합성음으로 대신한다. 출처는 `audio/CREDITS.md`.

시간은 현실 1분에 그곳의 30분씩 흐르고, 하단 슬라이더(또는 `,` `.` 키)로 조절한다. 문장에 노을·아침·밤이 있으면 그 시각에서 시작한다.
소리는 파일 없이 Web Audio로 합성한다: 표면별 발소리, 파도·바람·새·귀뚜라미·비·도시 소음, 시장·거리에서는 사람은 보이지 않고 웅성거림만 들린다. `M` 또는 버튼으로 끈다.

## 조작

| 조작 | 방법 |
| --- | --- |
| 둘러보기 | 화면 클릭 후 마우스 이동 (포인터 잠금). 터치는 드래그 |
| 멈추고 마우스 꺼내기 | `Esc` |
| 걷기 / 정지 | 하단 버튼 또는 `Space` |
| 걸음 (느긋이·천천히·걷기·빠르게·달리기) | 하단 버튼, `1`~`5`, `↑` `↓` |
| 시각 | 슬라이더, `,` `.` |
| 문장 입력 | `Enter` |
| 소리 | 버튼 또는 `M` |

## 로컬에서 열기

ES 모듈을 쓰므로 `file://`로 더블클릭하면 안 되고 서버로 띄웁니다.

```bash
npx serve .             # npx: npm 패키지를 설치 없이 실행 / serve: 현재 폴더(.)를 정적 서버로 띄움
python3 -m http.server  # 파이썬 내장 모듈로 현재 폴더를 8000번 포트에 서빙
```

API(`/api/*`)까지 함께 돌리려면 Vercel CLI를 씁니다.

```bash
npm i -g vercel         # -g: 전역 설치
vercel dev              # 정적 파일 + api/ 함수를 로컬에서 함께 실행
```

## Vercel 배포와 DB

GitHub `main`에 푸시하면 Vercel이 자동 배포합니다. 저장·통계·불편사항은 Neon Postgres를 씁니다.

1. Vercel 프로젝트 → **Storage** → **Create Database** → **Neon (Postgres)** → 프로젝트에 연결.
   연결하면 `DATABASE_URL` 환경 변수가 자동으로 들어옵니다. 테이블(`users`, `walks`, `events`, `feedback`)과 관리자 계정(`admin` / `admin1234`)은 첫 요청 때 자동으로 만들어집니다.
2. 연결 뒤 한 번 재배포(Deployments → Redeploy)하면 끝.

선택 환경 변수:

| 변수 | 용도 |
| --- | --- |
| `RESEND_API_KEY` | 불편사항을 메일로도 보냄 (Resend). 없으면 DB에만 저장 |
| `FEEDBACK_TO` | 받는 메일 주소 (기본 kwoos333@naver.com) |
| `FEEDBACK_FROM` | 보내는 주소 (Resend에 등록한 도메인) |

DB가 없을 때도 산책은 정상 동작하고, 저장·통계만 "아직 연결되지 않았습니다"로 안내합니다.

## API

| 메서드 | 경로 | 내용 |
| --- | --- | --- |
| GET | `/api/walks?limit=30` | 최근 저장된 길 |
| POST | `/api/walks` | `{ prompt, theme, meters, hour }` 저장 (Bearer 토큰) |
| GET | `/api/users?check=아이디` | 아이디 중복 확인 |
| POST | `/api/users` | `{ id, password, nickname }` 가입 → `token` |
| POST | `/api/auth` | `{ action: login\|me\|logout\|change\|reset, … }` 로그인·비밀번호 변경·(관리자) 초기화 |
| GET | `/api/walks?user=아이디` | 그 사람이 저장한 길 |
| GET | `/api/admin?what=summary\|users` | 관리자 전용 |
| POST | `/api/track` | 사용 사건 기록 (open, arrive, speed, walk, look, link, time, save, start) |
| GET | `/api/stats` | 집계 (관리자 토큰) |
| POST | `/api/feedback` | `{ message, contact?, page? }` 불편사항 |

## 이 데모의 범위

3D 장면은 브라우저 안에서 규칙으로 즉석 생성한 "체험용 미니 데모"입니다.
실제 서비스에서는 AI(예: World Labs Marble)가 생성한 3D 공간 위에 길을 깔고 같은 조작 방식으로 걷게 됩니다.
